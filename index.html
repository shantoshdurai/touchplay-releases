Download for Linux — latest release
Arch, Ubuntu, Fedora, Omarchy · Native uinput & Wayland / X11 · Python 3.10+

How to run on Linux

1

Extract the download and run ./setup.sh once — it creates a venv, installs the Linux dependencies, adds a desktop entry, and tells you if /dev/uinput needs fixing.

2

Run ./TouchPlay-Server.sh to launch the terminal dashboard.

3

Open TouchPlay on your phone — it connects instantly over Wi-Fi or USB.

4

Send videos anytime: touchplay-send <video.mp4> or drop into ~/Downloads/TouchPlay.

Architecture & Features

🪟 Windows

  • Standalone: Single portable .exe file
  • GUI: Rounded window, tray icon & drag-drop
  • Driver: Bundled ViGEmBus (Xbox 360 & DS4)
  • Mirror: DirectX Desktop Duplication (DXGI)
  • 2nd Screen: Bundled virtual display — Windows 10. Windows 11 needs a signed IDD driver
  • Drop: Downloads\TouchPlay

🐧 Linux

  • Lightweight: Fast Rich Terminal Dashboard (TUI)
  • Drivers: Kernel /dev/uinput (zero driver install)
  • Mirror: X11, plus grim on wlroots Wayland (Hyprland / Sway)
  • 2nd Screen: Headless virtual output (Hyprland only)
  • Drop: ~/Downloads/TouchPlay + CLI tool

Questions

Can I use my phone as a PC gamepad without any hardware?

Yes. Install TouchPlay on the phone from Google Play, run the free TouchPlay server on your PC, and both find each other automatically over the same Wi-Fi network. No dongle, cable or receiver is needed.

How many players can play at the same time?

Up to eight phones on one PC. Players 1–4 appear as Xbox 360 controllers and players 5–8 as DualShock 4 controllers, because Windows only exposes four Xbox XInput slots.

Which games does it work with?

Any PC game that accepts an Xbox or PlayStation controller. That includes Steam, Epic, Game Pass, emulators, and games streamed through Moonlight, Parsec or GeForce Now.

Can I use the phone as a second screen instead of just a mirror?

Yes. On Windows 10 the server adds a virtual display so the phone can extend your desktop. On Linux it creates a headless output on Hyprland. On Windows 11 you first need a Windows 11 capable virtual display driver installed — the bundled one is Windows 10 only.

Does it work over a USB cable?

Yes, and it is the lowest-latency option (under 1 ms). Turn on USB tethering and the app connects over the cable instead of Wi-Fi, which is useful on crowded networks.

Is TouchPlay free, and does it need an account?

It is free and there is no account, no sign-in, and no cloud. Your controller input, screen frames and files travel only between your phone and your own PC on your local network.

Can I build my own controller layout?

Yes. The built-in editor lets you add, drag, resize, rename and delete any button, stick, trigger, D-pad or mouse pad, bind each one to a gamepad button, keyboard key or mouse action, and save it as your own layout. Layouts can be shared as a text code.

Which operating systems does the PC server run on?

Windows 10 and 11, and Linux (Arch, Ubuntu, Fedora, and other distributions with /dev/uinput). The phone app is Android 8.0 and newer.
