Turn your Android phone into a real controller, trackpad, and second screen. High-performance native support for both Windows and Linux.

Download for Windows (64-bit)
Windows 10 & 11 · about 60 MB · Standalone .exe

How to run on Windows

1

Run TouchPlay-Server.exe (runs straight away, no installer needed; ViGEmBus bundled).

2

If Windows SmartScreen appears, click More info → Run anyway.

3

Open TouchPlay on your phone — it finds your PC automatically!

tar xzf touchplay-linux-source.tar.gz && cd touchplay && ./setup.sh
Download for Linux — latest release
Arch, Ubuntu, Fedora, Omarchy · Native uinput & Wayland / X11 · Python 3.10+

How to run on Linux

1

Extract the download and run ./setup.sh once — it creates a venv, installs the Linux dependencies, adds a desktop entry, and tells you if /dev/uinput needs fixing.

2

Run ./TouchPlay-Server.sh to launch the terminal dashboard.

3

Open TouchPlay on your phone — it connects instantly over Wi-Fi or USB.

4

Send videos anytime: touchplay-send <video.mp4> or drop into ~/Downloads/TouchPlay.

Architecture & Features

🪟 Windows

  • Standalone: Single portable .exe file
  • GUI: Rounded window, tray icon & drag-drop
  • Driver: Bundled ViGEmBus (Xbox 360 & DS4)
  • Mirror: DirectX Desktop Duplication (DXGI)
  • Drop: Downloads\TouchPlay

🐧 Linux

  • Lightweight: Fast Rich Terminal Dashboard (TUI)
  • Drivers: Kernel /dev/uinput (zero driver install)
  • Mirror: Wayland (grim) & X11 with GPU offload
  • 2nd Screen: Headless virtual output (Hyprland)
  • Drop: ~/Downloads/TouchPlay + CLI tool
